Loop 앱 신규 CGM 추가 방법 분석 보고서

검토 결과: 새로운 CGM 추가는 완벽하게 가능합니다.
Loop 앱은 유연한 플러그인 아키텍처(Plugin Architecture)를 채택하고 있어, Loop 코어 코드를 직접 수정하지 않고도 독립적인 플러그인 프레임워크를 개발하여 새로운 CGM 기기를 추가하고 연동할 수 있도록 설계되어 있습니다. (참고: LoopWorkspace 및 PluginManager.swift)

1. 새로운 CGM 추가에 필요한 정보

새로운 CGM 플러그인을 개발하고 연동하기 위해 다음 정보와 준비물이 필요합니다.

구분 상세 내용
Bluetooth (BLE) 명세 CGM 하드웨어와 통신하기 위한 서비스 UUID, 캐릭터리스틱 UUID, 연결 및 인증 프로세스, 데이터 패킷 구조에 대한 리버스 엔지니어링 또는 공식 문서가 필요합니다.
암호화 및 인증 알고리즘 많은 상용 CGM(예: Dexcom, Libre)은 자체적인 암호화 및 핸드셰이크 과정을 거칩니다. 이 통신 프로토콜을 해독하거나 처리할 수 있는 로직이 필요합니다.
필수 프로토콜 준수 LoopKit의 CGMManager, CGMManagerUI, CGMManagerUIPlugin 프로토콜을 모두 구현해야 Loop 앱에서 이를 인식하고 다룰 수 있습니다.
Apple 개발자 계정 블루투스 권한(CoreBluetooth) 백그라운드 모드 실행을 위해 디바이스에 직접 빌드할 때 필요합니다.

2. 새로운 CGM 추가 방법 및 빌드 과정

새로운 CGM은 LoopWorkspace 내에 서브모듈(Submodule)로 독립된 프레임워크 프로젝트를 만들어 추가해야 합니다.

1단계: 플러그인 프로젝트 생성

  1. Xcode에서 새로운 Framework 프로젝트 생성 (예: MyCustomCGMKit).
  2. 이 프로젝트를 LoopWorkspace 폴더 안에 위치시키고, Git 서브모듈로 등록합니다.

2단계: 프로토콜 구현 (핵심)

새로운 플러그인은 반드시 LoopKit에서 제공하는 프로토콜을 구현해야 합니다.

  • CGMManager (Data 로직): 블루투스 연결(CoreBluetooth), 데이터 수신, 혈당 값 파싱(Glucose 값으로 변환), 에러 처리 등을 담당.
  • CGMManagerUI (UI 로직): 기기 설정 화면, 센서 수명 상태, 상태 표시줄(Status Indicator) 등을 제공하는 뷰.
  • CGMManagerUIPlugin (진입점): Loop의 PluginManager가 이 플러그인을 찾고 인스턴스화 할 수 있게 해주는 팩토리 클래스.

3단계: Info.plist 키 설정

Loop가 이 프레임워크를 'CGM 플러그인'으로 인식하려면 프레임워크의 Info.plist에 다음 속성을 반드시 선언해야 합니다.

<key>com.loopkit.Loop.Plugin</key>
<true/>
<key>com.loopkit.Loop.cgmManagerIdentifier</key>
<string>MyCustomCGMManager</string>
<key>com.loopkit.Loop.cgmManagerDisplayName</key>
<string>My Custom CGM</string>

4단계: LoopWorkspace에 통합 및 빌드

  1. LoopWorkspace.xcworkspace를 엽니다.
  2. 새로 만든 MyCustomCGMKit.xcodeproj를 워크스페이스에 추가(Drag & Drop)합니다.
  3. Loop 프로젝트의 Target 설정 -> Build Phases -> Link Binary With Libraries에 MyCustomCGMKit.framework를 추가합니다.
  4. 동일하게 Build Phases의 Copy Files (Plugins) 페이즈에 MyCustomCGMKit.framework를 추가하여, 빌드된 앱의 플러그인 디렉토리에 복사되도록 설정합니다.
  5. 루프 타겟(Loop Target)을 선택하고 디바이스로 빌드(Build & Run)합니다.

3. UI 상에서 선택 가능하게 하는 방법

플러그인 프레임워크가 정상적으로 빌드되어 앱 패키지(Bundle)의 PlugIns 폴더 안에 복사되면, 별도로 Loop 앱의 코드를 수정하지 않아도 UI에서 선택이 가능해집니다.

동작 원리:
Loop 앱이 켜질 때 PluginManager.swift가 앱의 Plugin 폴더를 스캔합니다. Info.plist에 com.loopkit.Loop.cgmManagerIdentifier가 정의된 프레임워크를 찾으면 리스트업(availableCGMManagers) 합니다.
이후 사용자가 설정 화면에서 "CGM 추가" 버튼을 누르면, 이 리스트를 바탕으로 목록을 만들어 보여주며, 플러그인에 구현된 CGMManagerUI 화면을 띄우게 됩니다.

4. 전체 흐름도 (Mermaid 플로우 차트)

아래 흐름도는 커스텀 CGM 데이터를 수신하여 UI에 뿌려주기까지의 전체 과정을 나타냅니다.


sequenceDiagram
    participant User as User (Loop UI)
    participant Loop as Loop App (PluginManager)
    participant CustomKit as MyCustomCGMKit (Plugin)
    participant CoreBluetooth as CoreBluetooth
    participant Sensor as Custom CGM Sensor

    Note over User, CustomKit: 1. 플러그인 로드 및 등록
    Loop->>Loop: App 시작 시 Plugin 폴더 스캔
    Loop->>CustomKit: Info.plist 분석 (Plugin 식별자 확인)
    Loop->>Loop: 사용 가능한 CGM 목록에 "My Custom CGM" 추가

    Note over User, CustomKit: 2. UI 기기 선택 및 연동
    User->>Loop: "Add CGM" 선택
    Loop->>User: "My Custom CGM" 표시
    User->>Loop: "My Custom CGM" 선택
    Loop->>CustomKit: setupViewController() 호출
    CustomKit->>User: 설정/연결 안내 화면 제공
    User->>CustomKit: 페어링 시작

    Note over CustomKit, Sensor: 3. 블루투스 연결 및 데이터 수집
    CustomKit->>CoreBluetooth: 스캔 시작 및 센서 연결
    CoreBluetooth->>Sensor: BLE Connection
    Sensor-->>CoreBluetooth: Notification (혈당/raw 데이터)
    CoreBluetooth-->>CustomKit: Data Packet 수신

    Note over CustomKit, Loop: 4. 데이터 파싱 및 앱 전달
    CustomKit->>CustomKit: 패킷 파싱, 암호화 해제 -> GlucoseValue로 변환
    CustomKit->>Loop: 새로운 혈당 값(Glucose Sample) 전달
    Loop->>Loop: Loop 알고리즘(DoseMath) 실행, 차트 UI 업데이트
    Loop->>User: 화면에 혈당 값 및 추세 표시
